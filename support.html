Support

Email support@channelkeys.net. We answer within one business day; data-quality reports usually within hours.

Refresh schedule

Listings refresh weekly, early Sunday morning US Eastern time. The meta_source_run table in every listing shows the source file, size, checksum and agency timestamp behind the current refresh, and META_REFRESH shows when it was loaded.

Source cadence

  • FDA NDC Directory: updated daily by FDA; we pick up the latest file each week.
  • FDA Orange Book data files: updated monthly by FDA.
  • Medicaid State Drug Utilization Data: updated quarterly by CMS, with restatements.
  • 340B OPAIS: HRSA publishes a daily export; we snapshot it weekly and log changes.
  • CMS Open Payments: republished in June and January each year.

Reporting a data issue

Send the table name, the key (for example an NDC-11 or 340B ID), what you expected and what you saw. If the source agency's file is wrong we will say so and point to it; if our transformation is wrong we fix it in the next refresh and note it in the listing's release notes.

Requests

Need another public source joined in, a different grain, or a private listing with custom tables? Write to hello@channelkeys.net.
