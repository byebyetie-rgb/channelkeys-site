Data dictionary

Every table and column in the Channel Keys listing. Refer to objects as CORE.<TABLE> under the database name you choose when you get the listing. Column names are plain uppercase identifiers, so no quoting is needed.

Keys and conventions

  • NDC11: 11-digit, zero-padded 5-4-2 NDC. XREF_NDC_FORMATS maps every FDA 10-digit format to it.
  • APPL_TYPE and APPL_NO: the Orange Book application key (N for NDA, A for ANDA), APPL_NO zero-padded to six digits.
  • LABELER_CODE: the first five digits of the NDC. DIM_LABELER carries the best labeler name and the matched Open Payments manufacturer with its match score.
  • ID_340B: the HRSA covered entity ID. Contract pharmacies key on ID_340B plus CONTRACT_ID.
  • SNAPSHOT_DATE: the refresh a row came from. CHANGE_LOG compares consecutive refreshes; META_SOURCE_RUN records the agency files behind each one.
  • Derived fields (EST_LOE_DATE, IS_DISCONTINUED, IS_ACTIVE, manufacturer matches) are ours. Validate before regulatory or contractual use.
